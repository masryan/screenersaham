File yang dihasilkan:
  1. quant-hub.css  — CSS untuk fitur baru
  2. quant-hub.js   — JavaScript untuk fitur baru (baca data dari state.stocks & broker_summary)

Fitur yang ditambahkan (menu ⚡ Quant Hub di sidebar):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 DASHBOARD
  • Metrik pasar ringkas: Total Saham, Undervalue, Score Rata-rata,
    Danger Zone, Fair Value, Top Candidate, Volume Total
  • IHSG Chart (TradingView) + Status Buka/Tutup bursa
  • Ticker Tape otomatis di bawah chart IHSG
  • Ultimate Score Top 30 — formula transparan:
    Fundamental 50 + Valuasi 25 + Momentum 25 = Skor 0-100
  • Est. Upside % berbasis PER/PBV vs ROE

🔥 BANDARMOLOGY
  • ARA Candidate: saham small-mid cap dengan close di high, offer
    tipis/kosong, belum kena ARA — diurutkan per kombinasi BID, OFF, ATS, Non-Regular, Top Vol
  • Swing Big Cap: saham large cap dengan net foreign buy konsisten 1-3 hari
  • Disclaimer jelas bahwa ini berbasis data EOD, bukan jaminan

◉ BROKER STALKER (2 mode)
  • LACAK BROKER: masukkan 1 kode broker (mis. AK/OD), pilih periode
    → lihat semua saham yang dibeli/dijual broker itu, berapa besar
    net buy/sell per saham
  • LACAK SAHAM: masukkan 1 kode saham, pilih periode
    → lihat top 12 broker yang paling aktif beli/jual saham itu
  • Sumber: tabel broker_summary di Supabase Anda (sudah ada)

◈ FAVORIT P&L
  • Tabel watchlist dengan kolom: Ticker, Nama, Sektor, Harga Entry,
    Harga Kini, P&L%, 1D%, Status (FAIR/OV/UV/DANGER)
  • Set/clear harga entry per saham dari tombol di tabel
  • Ringkasan P&L total + tombol Share (salin ringkasan ke clipboard)
  • Status badge otomatis dari valuasi & P&L (FAIR / OV / UV / DANGER)

CARA PASANG (3 langkah mudah, ±2 menit):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Salin 2 file ini (quant-hub.css & quant-hub.js) ke folder Anda:
   C:\...\screenersaham-main\screenersaham-main\screener\
   (sejajar index.html, styles.css, app.js)

2. Buka index.html, cari baris sebelum </body>, tambahkan:
   (atau cari tempat yang tepat di <head> untuk CSS & sebelum </body> untuk JS)

   <link rel="stylesheet" href="quant-hub.css">
   <script src="quant-hub.js"></script>

   ⚠️  PENTING: Urutan WAJIB
   - quant-hub.css  SETELAH styles.css
   - quant-hub.js   SETELAH app.js  (karena quant-hub.js membaca state.stocks & fungsi dari app.js)

3. Buka/reload browser → klik menu ⚡ Quant Hub di sidebar

TIDAK PERLU ubah database, app.js, atau SQL — hanya tambah 2 baris di HTML.

Formula "Ultimate Score" (bukan tiruan ihsgscreener):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Formula ini DIBUAT SENDIRI dari nol dengan prinsip transparan:
• Fundamental 50pt: ROE(12) + NPM(8) + DER(10) + CurrentRatio(5) + DivYield(5) + EPS/Valuasi(10)
• Valuasi 25pt:     PER vs ROE target (15) + PBV vs ROE target (10)
• Momentum 25pt:    Price > MA50(8) + Price > MA200(7) + RSI 40-70(5) + Trend Bullish(5)
• Est. Upside:      Fair PER = ROE*0.8, Fair Price = price × (FairPER/PER)

Semua angka & bobot bisa diedit di dalam fungsi qhUltimateScore() di quant-hub.js.

Jika ada error:
━━━━━━━━━━━━━━
• "state is not defined" → urutan JS salah: pastikan quant-hub.js di bawah app.js
• "sidebarNav tidak ditemukan" → sidebar di file HTML menggunakan ID yang beda; cek index.html
• Data tidak muncul → pastikan tab Screener sudah pernah dibuka (memanggil loadLive() dulu)
• Broker Stalker "Tidak ada data" → pastikan tabel broker_summary sudah terisi (dari Broker Summary di aplikasi)
