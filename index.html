Perlu diuji dulu: endpoint orderbook belum tentu membawa field Open/High/Low/Last, mungkin cuma bid/offer saja.
✅ Sudah terverifikasi berfungsi. Beda dari "Endpoint Quote/Orderbook" di atas — yang ini khusus tangga bid/offer 10 level di panel Detail Emiten, dan nilainya ikut tersimpan ke Supabase supaya tidak hilang saat dibuka di browser lain.
⚠️ Kalau diisi manual, pastikan bagian akhir tetap &limit={limit} (placeholder, bukan angka mati) — kalau ditimpa jadi angka tetap seperti &limit=200, data hari-hari yang lebih lama bisa kepotong dan cuma 1 hari terakhir yang kesimpan.
⚠️ Endpoint default memaksa data_type=BROKER_DISTRIBUTION_DATA_TYPE_VALUE — ini kemungkinan alasan kolom Lot selalu kosong (server cuma diminta kirim data Nilai, bukan Volume/Lot). Coba ganti jadi BROKER_DISTRIBUTION_DATA_TYPE_VOLUME di kotak endpoint di atas lalu tes lagi di bawah — kalau JSON mentahnya berubah isi jadi angka lot, berarti itu solusinya (tinggal gabung dua request VALUE+VOLUME). Tes ini baca langsung dari kotak endpoint di atas (belum perlu disimpan dulu).

Pakai token akunmu sendiri secara bertanggung jawab dan hormati rate limit.

🔔 Notifikasi Telegram (Rules Kustom)

Kirim notifikasi Telegram otomatis kalau ada saham baru yang lolos preset Rules Kustom pilihanmu — jalan di server (Cron), jadi tetap terkirim walau aplikasi ini tidak sedang dibuka. Butuh setup 1x: jalankan sql/06_telegram_notifikasi.sql di Supabase, deploy functions/telegram-notifier, lalu isi field di bawah ini.
📖 Cara bikin Bot Telegram & dapat Chat ID (belum punya?)
  1. Buka Telegram, cari @BotFather, kirim perintah /newbot, ikuti instruksinya (kasih nama & username bot).
  2. BotFather akan membalas dengan token (contoh: 123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) — salin ke field "Bot Token" di bawah.
  3. Cari & mulai chat dengan bot barumu (klik link dari BotFather atau cari usernamenya), kirim pesan apa saja (mis. "hi") supaya bot "kenal" kamu.
  4. Untuk dapat Chat ID: cari @userinfobot di Telegram, kirim /start, dia akan membalas dengan ID akunmu (angka, contoh: 987654321) — salin ke field "Chat ID".
  5. Kalau mau notifikasi masuk ke grup, tambahkan bot ke grup itu, lalu pakai Chat ID grup (biasanya diawali tanda minus, mis. -1001234567890 — bisa dicek lewat @RawDataBot atau membuka https://api.telegram.org/bot<token>/getUpdates setelah mengirim pesan ke grup).

👋 Selamat Datang di IHSG Screener Pro

Aplikasi screener saham IHSG — teknikal, fundamental, dan Bandarmologi dalam satu tempat. Berikut cara mulai paling cepat:
  1. Buka ⚙️ Pengaturan → isi Supabase URL & Key supaya data bisa dimuat (sekali saja, tersimpan di browser ini).
  2. Klik 🔄 Refresh Data di header untuk memuat data terbaru.
  3. Pakai 📋 Screener untuk filter cepat (preset siap pakai) atau cari ticker/nama emiten langsung.
  4. Mau kriteria sendiri? Buka panel Rules Kustom di Screener — bisa disimpan jadi preset.
  5. Simpan saham menarik ke ⭐ Watchlist, atau uji strategi di 🔬 Backtest.
Butuh detail tiap fitur, atau fitur developer (WS Debug dll.)? Buka tab 📖 Panduan — toggle "Mode Lanjutan" untuk menampilkannya ada di ⚙️ Pengaturan.
