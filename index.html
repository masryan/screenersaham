Ini API tidak resmi (bukan API publik Stockbit) — endpoint bisa berubah kapan saja, dan token disimpan HANYA di Local Storage browser ini (tidak dikirim ke server manapun selain langsung ke Stockbit/proxy yang kamu tentukan sendiri).

⚠️ Endpoint default TERBUKTI SALAH (itu API "Stream"/linimasa komentar, bukan API harga) — Open/High/Low/Last tidak akan pernah muncul benar selama field ini masih kosong/default. Pakai kotak uji di bawah untuk mencari & memverifikasi endpoint yang benar lewat DevTools browser (Network tab) di stockbit.com, sebelum disimpan.
⚠️ Kalau diisi manual, pastikan bagian akhir tetap &limit={limit} (placeholder, bukan angka mati) — kalau ditimpa jadi angka tetap seperti &limit=200, data hari-hari yang lebih lama bisa kepotong dan cuma 1 hari terakhir yang kesimpan.
✅ Endpoint sudah dicek manual lewat DevTools (mode Daily). Mode Weekly/Monthly baru tebakan pola nama parameter — kalau ternyata salah/data janggal, kabari supaya bisa dikoreksi.
⚠️ Endpoint di atas belum terverifikasi 100% (hasil pengamatan komunitas, bukan dokumentasi resmi Stockbit) dan browser kemungkinan besar akan memblokirnya karena CORS kalau dipanggil langsung dari halaman ini. Kalau muncul error CORS, isi "Proxy URL" dengan Supabase Edge Function kecil yang meneruskan request + header Authorization dari sisi server (lihat file stockbit-proxy yang disediakan terpisah). Pakai token akunmu sendiri secara bertanggung jawab dan hormati rate limit.
🔄 Field Token di atas bisa terisi otomatis lewat extension Chrome stockbit-token-extension (jalankan dulu sql/05_stockbit_token_sync.sql di Supabase). Kalau sudah terpasang & kamu pernah buka stockbit.com dalam kondisi login, token akan tersinkron sendiri setiap kali modal ini dibuka.

🔔 Notifikasi Telegram (Rules Kustom)

Kirim notifikasi Telegram otomatis kalau ada saham baru yang lolos preset Rules Kustom pilihanmu — jalan di server (Cron), jadi tetap terkirim walau aplikasi ini tidak sedang dibuka. Butuh setup 1x: jalankan sql/06_telegram_notifikasi.sql di Supabase, deploy functions/telegram-notifier, lalu isi field di bawah ini.
📖 Cara bikin Bot Telegram & dapat Chat ID (belum punya?)
  1. Buka Telegram, cari @BotFather, kirim perintah /newbot, ikuti instruksinya (kasih nama & username bot).
  2. BotFather akan membalas dengan token (contoh: 123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) — salin ke field "Bot Token" di bawah.
  3. Cari & mulai chat dengan bot barumu (klik link dari BotFather atau cari usernamenya), kirim pesan apa saja (mis. "hi") supaya bot "kenal" kamu.
  4. Untuk dapat Chat ID: cari @userinfobot di Telegram, kirim /start, dia akan membalas dengan ID akunmu (angka, contoh: 987654321) — salin ke field "Chat ID".
  5. Kalau mau notifikasi masuk ke grup, tambahkan bot ke grup itu, lalu pakai Chat ID grup (biasanya diawali tanda minus, mis. -1001234567890 — bisa dicek lewat @RawDataBot atau membuka https://api.telegram.org/bot<token>/getUpdates setelah mengirim pesan ke grup).
